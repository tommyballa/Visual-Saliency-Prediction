# Visual-Saliency-Prediction
Accurately predicting visual saliency remains a critical challenge in computer vision, essential for simulating the selective attention mechanisms of the Human Visual System (HVS). While Convolutional Neural Networks (CNNs) have driven significant improvements in human attention prediction, Vision Transformers offer a powerful alternative for capturing global contextual dependencies. In this report, we propose an end-to-end deep learning architecture based on a Swin-Transformer (Swin-T) encoder paired with a skip-layer convolutional decoder. Our model captures hierarchical saliency information, merging deep, coarse global features with shallow, fine-grained local responses. To optimize learning, we introduce a custom Hybrid Loss function that balances Kullback-Leibler (KL) divergence with the Pearson Correlation Coefficient (CC). Furthermore, we implement a robust inference pipeline featuring Multi-Scale Test-Time Augmentation (TTA). Experimental evaluations on SALICON dataset, demonstrate that our method achieves highly competitive results, including a CC of 0.9037 and a SIM of 0.7903, positioning it as a robust solution for state-of-the-art visual attention prediction.
